One image: the open passport spread of the Republic of Sulara, an
invented desert salt-pan republic. The data page holds a drawn portrait
of Layla Amira Haddad, a salt caravan guide, with a machine-readable
strip whose check digits are computed. The visa page holds six
entry/exit stamps from three neighbouring countries, every date falling
between the passport's issue (12 MAR 2024) and expiry (12 MAR 2034),
and the telling detail: CONDITION 7, the salt caravan permit — the
White Pan may be crossed only between first and last light.

## How it works

`draw.py` draws `entry.png` (1024×1024, PIL only, deterministic —
no randomness, no network, no clock). `main.py` copies `entry.png` to
`/output/entry.png` using only the standard library, so both runs write
the same bytes.
